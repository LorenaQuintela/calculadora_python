# Calculadora em Python / Simulando a do celular que pede um valor inicial.

  Projeto desenvolvido durante meus estudos de Python com o objetivo de praticar lógica de programação.

  Comecei desenvolvendo o projeto me desafiando a estruturá-lo com base na apresentação feita no terminal pelo orientador do meu curso de lógica. 
  
  Consegui estruturar o menu, organizar as funções e implementar as operações matemáticas.

  Durante o desenvolvimento encontrei dificuldades na parte de tratamento de entradas, formatação dos resultados e tratamento de exceções.
  
 # Aprendizados

  Compreendi conceitos que ainda não conhecia, como:

  - utilização de break e continue;
  - tratamento de exceções com try/except;
  - organização do código utilizando uma função main();
  - importância da validação de entradas do usuário.

  Este projeto me mostrou que pesquisar, compreender soluções existentes e adaptá-las faz parte do processo de aprendizado.


# Funcionalidades

  - Soma
  - Subtração
  - Divisão
  - Raiz quadrada
  - Logaritmo na base 2
  - Menu interativo
  - Validação das opções
  - Tratamento de entradas inválidas
  - Tratamento de divisão por zero
    
# Tecnologias

  - Bibliotecas externas termcolor
  - Git
  - GitHub

# Conceitos praticados

  - Estruturas condicionais (if, elif e else)
  - Operadores de associação (in e not in)
  - Laços de repetição (while)
  - Controle de fluxo (`break` e `continue`)
  - Funções
  - Organização da aplicação utilizando main()

  # Como executar
  ### Clone o repositório

  git clone git@github.com:LorenaQuintela/calculadora_python.git

  ### Entre na pasta
  
  cd calculadora_python

  ### Execute a aplicação

  python main.py
